Changing or updating the website
1.SSH into the VM
	Download "SSH.pem" from GitHub
	Open "command prompt" on windows
	type and enter "cd downloads"
	enter "ssh -i "SSH.pem" ec2-user@ec2-3-143-168-22.us-east-2.compute.amazonaws.com"
	reply to the prompt with "yes" and you are in the VM
2.Download the repo from GitHub
	type and enter "sudo git clone https://github.com/Simpsonkr/360VirtualREalityMobileSite.git"
3.Copy the repo to the Apache files
	type and enter "sudo cp -r 360VirtualREalityMobileSite/* /var/www/html/"
4.load the website

You should not need to delete anything as long as the file structure is still the same, since the files you are downloading are the same as what is on the system, the new files will replace the old files.

If AWS ever goes down, the IP will change and the URL will change with it
1.Log into AWS as the IAM user
2.Navigate to Services>Compute>EC2
3.Navigate to "Instances"
4.Click the "instance ID" for the "vr360usac" instance
5.Locate the IPv4 address, this is the new IP address.
6.Change the IP in the URL to this new IP and connect to the website.

If the command from line three of "SSH into the VM"  is not working, follow all the step in "If AWS ever goes down"
1.Locate "Connect" in the top right
2.Navigate to "SSH client"
3.Copy the command in the "Example" section
4.Please also update the command in this file
