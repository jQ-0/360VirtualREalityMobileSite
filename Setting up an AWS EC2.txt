After making an AWS account and signing in as a root user
1. Navigate to the "EC2" services
2. Click the orange "Launch Instance" near the center of the screen
3. Give the instance a name like "USAC360VR"
4. Scroll down to "Instance type" and select "t2.micro"
5. Scroll down to "Key pair (login)"and "create key", give the key a name like ssh or security, then press "Create key pair". This will start a download of the key.
6. Select the orange "Launch instance" that is to the right side of the screen.
7. Select "EC2 Instance Connect Tab" and click "Connect" in the bottom-right. This will make a new tab that is in Linux
8. In Linux, enter "sudo yum update -y", wait for the command to finish. This updates linux
9. Enter "sudo yum install -y httpd", wait for command to finish. This installs Apache, the program that hosts the website.
10. Enter "sudo systemctl start httpd", this starts Apache
11. Enter "sudo systemctl enable httpd", this causes Apache to start on boot if the EC2 instance goes down.
12. Enter "sudo yum install git -y", this installs git to the Linux machine
13. Enter "sudo git clone https://github.com/Simpsonkr/360VirtualREalityMobileSite.git,(I'm sorry you cannot copy paste this), this installs the repo
14. Enter "sudo cp -r 360VirtualREalityMobileSite/* /var/www/html/, this copies the repo to the web root directory
15. Now back to the original tab, in the "Connect" window, click the link that is in the "Security groups" section.
16. In "Inbound Rules" click the "Edit inbound rules" button
17  The "Type" needs to be changed to "HTTP" in the dropdown menu, in the box with the search icon select "0.0.0.0/0"
18. Select "Add rule", in the new line, change the type to "SSH", and the search bar box to "0.0.0.0/0".
19. Select "Save rules"
20. Navigate back to the EC2 instance and select its "Instance ID", then locate the "Public IPv4 address"
21. "http://IP Address/Vr%20mobile%20app%20code/assets/html/index.html",will be the url for the website.
